# Graal Worlds 6.114 (scaffold)

An empty shell for the Worlds host, in Delphi (Object Pascal). The
original is a Unity player plus a native Graal plugin. This program names
the IL2CPP assemblies and exits. It does not play the game.

> **Not affiliated.** graal-delphi is an independent fan project. It is not
> affiliated with, endorsed by, or connected to Graal Online, Cyberjoueurs,
> or Stéphane Portha ("unixmad").

## What's new in v0.0.5
