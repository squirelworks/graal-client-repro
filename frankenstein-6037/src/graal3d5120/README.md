# v5.120 Graal3D

Placeholder for the Graal3D half of the mix, folded into the v6.037 host.

v5.120 is the 5.12 client, written the way the 6.x builds are
(6.03r7 is v6.037, 6.1.1.3 is v6.113). Its rebuilds are
[`graal-5.12-G3D14097`](../../../graal-5.12-G3D14097/) (Windows, token
`G3D14097`) and
[`graal-5.12mac-G3D15097`](../../../graal-5.12mac-G3D15097/) (Mac OS X,
token `G3D15097`, built from the same engine source). Read Graal3D
behaviour from those folders. Both split a Delphi launcher from
`GraalEngine.dll` and `Graal3DEngine.dll`.

No renderer and no world code live here yet. This slot is the older
Graal3D generation. It is not a modern Torque3D base. A small MIT-licensed
piece from modern Torque3D is allowed only where that older Torque needs
it.
