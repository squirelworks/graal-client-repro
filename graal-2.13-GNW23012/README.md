# Graal 2.13 (`GNW23012`), inferred

**No binary of Graal 2.13 is held.** The token is the one gs2lib's version
table lists for 2.13. Squirrel asked for every listed token to have a
client (2026-11-13), so this folder is the nearest real rebuild,
`graal-2.1.0.0-GNW31101`, with the token and the build label changed.
Everything else (forms, art, Training levels, behaviour) is 2.1.0.0's, and
should be read as such.

What is known of 2.13 itself: release notes: gani attributes to #P9; the PM translate button.

## The link

The link is 2.1.0.0's: generation 3, the login line type 0, the key byte, `GNW23012`, account and password, then PLI_LANGUAGE.

## Where it finds its files

As the 2.1.0.0 rebuild, under `graal-assets/2.13/` first and then 2.1.0.0's folders.
It carries 2.1.0.0's program resources but **not** its install: put a 2.x install
next to it, or a `graal-assets/` folder, or point at one with `--data`.

## Checks for 0.0.1

- Builds with Free Pascal on Windows; its tests pass with no leaks.
- There is no real client to compare with.
