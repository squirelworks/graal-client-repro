# Graal 2.13 (GNW23012), 0.0.1, inferred

A client that logs in with `GNW23012`, the token gs2lib lists for Graal 2.13. No
binary of 2.13 is known; this is the 2.1.0.0 rebuild with that token. It is
for testing servers with the 2.13 login.
