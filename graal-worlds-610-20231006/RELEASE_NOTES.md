# Graal Worlds 610 (scaffold)

A scaffold for Worlds build 610, in Delphi (Object Pascal). It names
the build (Unity 2022.3.9f1, built 2023-10-06) and exits. It does not play
the game.

**Login token: none.** The original sends no version token, so there is nothing to check here.
