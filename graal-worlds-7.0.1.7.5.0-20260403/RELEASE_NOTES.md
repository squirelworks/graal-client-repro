# Graal Worlds 7.0.1.7.5.0 (scaffold)

A scaffold for Worlds build 7.0.1.7.5.0, in Delphi (Object Pascal). It names
the build (Unity 6000.0.63f1, built 2026-04-03) and exits. It does not play
the game.

**Login token: none.** The original sends no version token, so there is nothing to check here.
