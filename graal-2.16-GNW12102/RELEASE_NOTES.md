# Graal 2.16 (GNW12102), 0.0.1, inferred

A client that logs in with `GNW12102`, the token gs2lib lists for Graal 2.16. No
binary of 2.16 is known; this is the 2.17.1 rebuild with that token. It is
for testing servers with the 2.16 login.
