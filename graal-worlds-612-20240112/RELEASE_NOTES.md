# Graal Worlds 612 (scaffold)

A scaffold for Worlds build 612, in Delphi (Object Pascal). It names
the build (Unity 2023.2.3f1, built 2024-01-12) and exits. It does not play
the game.

**Login token: none.** The original sends no version token, so there is nothing to check here.
