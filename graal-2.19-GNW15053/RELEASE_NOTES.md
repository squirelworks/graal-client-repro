# Graal 2.19 (GNW15053), 0.0.1, inferred

A client that logs in with `GNW15053`, the token gs2lib lists for Graal 2.19. No
binary of 2.19 is known; this is the 2.17.1 rebuild with that token on the generation-4 link 2.19 to 2.21 used. It is
for testing servers with the 2.19 login.
