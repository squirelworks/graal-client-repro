# Frankenstein (v6.113 + v5.120 Graal3D, from the 5.12 repro)

Community experimental client. Releases use the tag prefix
`frankenstein-v` from `.github/workflows/frankenstein.yml`. They are a
separate series from the combined graal-client-repro release.

> **Not affiliated.** graal-delphi is an independent fan project. It is not
> affiliated with, endorsed by, or connected to GraalOnline or
> graalonline.com, Cyberjoueurs, or Stéphane Portha ("unixmad").

## What's new in frankenstein-v0.0.1

- Scaffold only. Directory layout for a v6.113 host, a v5.120 Graal3D
  fold-in, and a UDP path that stays enabled. Stub build and test write a
  manifest for macOS, Linux, and Windows. macOS is the first real target
  once a client exists. No playable client in this version.

## Not yet

- The client itself: v6.113 host, v5.120 Graal3D, UDP on the game
  connection, and macOS, Linux, and Windows builds of that program.
